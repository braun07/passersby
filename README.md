# Passersby

Small React + TypeScript app that pulls twelve random people from [randomuser.me](https://randomuser.me) and lays them out in a grid.

Built to practice fetching data, loading/error UI, and SCSS modules.

## Run it

```bash
npm install
npm run dev
```

## Stack

- Vite + React 19 + TypeScript
- SCSS (global reset/tokens + CSS modules for cards)
